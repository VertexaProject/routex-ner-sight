# RouteX Vision

Build the initial frontend for RouteX, an AI-powered logistics and accessibility intelligence platform for India's North Eastern Region based on SIH26002.

Create only the frontend UI for now. Do not add backend, database, authentication logic, n8n, ML or external API integration yet.

Create these screens:

Login / Demo Role Selection

 Authority

 Field Officer

 Convoy Driver

Authority Dashboard

 Large interactive map area as the main focus

 NER map covering Arunachal Pradesh, Assam, Manipur, Meghalaya, Mizoram, Nagaland, Sikkim and Tripura

 Road status: Open, Caution, High Risk, Blocked

 Vehicle markers

 Incident markers

 Weather/risk summary

 Active alerts

 Affected deliveries

Field Officer Screen

 Incident type

 Location

 Photo upload

 Description

 Severity

 Submit Incident

Convoy Driver Screen

 Current route

 Destination

 ETA

 Current road status

 Hazard warning

 Alternate route

Design the UI as a clean, minimal, professional Apple Liquid Glass-inspired interface. Keep the map visually dominant and avoid excessive cards or decorative elements.

Use realistic demo/mock data for now. Make the application responsive and organize the code cleanly so APIs and backend services can be connected later.
